# Atelier Vault

画像と生成プロンプトを、自分のMEGAに非公開で保存する静的Webアプリです。

**公開アプリ:** https://fruitflute.github.io/Atelier-Vault/

公開されるのはアプリのコードです。作品・プロンプト・MEGA認証情報をGitHubへ保存する機能はありません。最初はデモモードで起動します。

## 使い方

1. 公開アプリを開き、デモで登録・検索・詳細・再利用を試します。
2. 「MEGAに接続」からご自身でログインします。2段階認証にも対応します。
3. 小さなテスト画像1枚とプロンプトを保存します。
4. MEGA公式アプリで `PromptGallery/records/` 内の保存を確認します。
5. 別端末で同じURLを開いてログインし、更新して保存内容を確認します。

デモのデータは再読み込みや接続切り替えで消えます。MEGA接続切り替え時には入力中の作品情報・選択画像も消去します。デモの保存先表示を確認してから保存してください。

## v0.7: 全画面鑑賞とスクロール量の調整

ギャラリーの「全画面で鑑賞」で、検索・並び順を反映した画像一覧を順番に見られます。作品詳細から開く場合は、その作品の画像だけを表示します。左右ボタン・矢印キーで移動し、閉じるボタン／Escapeで戻れます。対応ブラウザでは右上の拡大ボタンでブラウザ自体も全画面にできます。

画像は切り抜かずに表示します。重複した見出しとフォーム間隔を整理し、広い画面では選択欄を二列に配置。スマホの画像カードは画像の縦横比に合わせ、不要な上下の空白を減らしました。配色・紙の意匠・文字サイズ・44px以上のボタンは保持しています。比較測定は [画面調整の記録](docs/VIEWER-LAYOUT.md) に記載しています。

## v0.6: 仕上がりを選ぶ

「つくる」上部の「仕上がり」で、従来のセルフィーらしい自然さと、光・ピント・色調を整えるプロフェッショナルな仕上げを切り替えられます。撮影視点は本人セルフィーのままです。個別指定したフィルム質感・手ブレなどは保持します。設定の保存・作品からの呼び戻しにも対応します。

## v0.5: プロンプトをつくる・衣装を増やす

「つくる」から衣装・情緒・状況を選び、プロンプトを組み立てられます。「詳細」を開くと元案の構図・光・髪・身体などの設定も使えます。文章量は簡潔／標準／丁寧から選び、コピーして外部の画像生成AIへ渡します。

- 標準衣装419件を名前・種類で検索。お気に入り、最近使った衣装、雰囲気・色・素材・パックによる絞り込みにも対応。
- ひらめきは採用前に比較する方式。衣装・配色・ディテールを固定でき、手書きの補足は保持します。
- 「この設定で作品を残す」から画像を登録すると、制作設定も作品へ添付。詳細画面から設定を呼び戻せます。
- 追加パック・お気に入り・設定の控えは**このブラウザに保存**し、MEGAへ自動同期しません。パックと設定はファイルで持ち運べます。認証情報は保存しません。
- 衣装パックの [形式](packs/FORMAT.md)、[記入例](packs/example.json)、[別のAIへの依頼文](packs/AI-REQUEST.md) を用意しています。
- 原案との対応と動作修正は [移植記録](docs/STUDIO-MIGRATION.md) を参照してください。

## ローカル起動

Node.js 22以降を使用します。

```sh
npm ci
npm start
```

http://127.0.0.1:8000 を開きます。配信用ファイルとMEGAJSは同梱済みなので、起動だけなら `node scripts/serve.mjs` でも利用できます。サーバーはローカル端末だけに接続を許可し、アプリの必要ファイルだけを配信します。

## 検証とビルド

```sh
npm ci
npm run check
npx playwright install chromium
npm test
```

`npm run build` は静的サイトを `dist/` に出力します。MEGAJS同梱ファイルがlockfileで取得したnpmパッケージと一致することも確認します。`node scripts/serve.mjs --dist` で配信用成果物を確認できます。

## GitHub Pages運用

リポジトリの Settings → Pages → Source を **GitHub Actions** に設定します。

`main` 更新時に `.github/workflows/pages.yml` が依存関係の復元、構文チェック、ビルド、PC・スマホのブラウザテストを実行し、成功した `dist/` だけを公開します。Pull Requestでは検証のみ行います。失敗時は Actions のログを確認してください。修正を `main` に入れるか、過去の変更をrevertして再デプロイできます。

別のホスティング先にも `dist/` だけをHTTPSで配信できます。`node_modules/`、テスト、管理用スクリプトをWeb配信する必要はありません。

## データと接続

- 対応画像: PNG / JPEG / WebP / GIF、各20MB、1作品8枚まで。
- 保存先: MEGAの `PromptGallery/records/work-<timestamp>-<id>/`。
- 画像・JPEGサムネイルを保存した後、最後に `record.json` を保存します。中断した保存は一覧に表示せず、途中のフォルダは可能ならごみ箱へ移します。
- 削除は `delete(false)` により、ごみ箱への移動を明示します。永久削除APIは呼びません。
- 共有リンクは作りません。ログイン情報やセッションをlocalStorageやCookieへ保存しません。ページ更新時は再ログインが必要です。
- ブラウザのパスワード保存・自動入力機能はブラウザ側の設定です。
- 同時編集、転送制限時の再開、大量作品のページングは未対応です。個人の小規模運用を想定しています。
- MEGAのごみ箱保持期限や容量制限はMEGA側の設定に従います。重要な作品は別途バックアップしてください。

## 依存ライブラリとプライバシー

MEGAJS **1.3.10** はMEGAの非公式SDKです。npmから取得したブラウザ用ビルドを `vendor/megajs-1.3.10.mjs` として同梱しています。実行時CDN依存やアクセス解析はありません。初回ページ取得はGitHub Pages、ログイン・同期・保存はブラウザからMEGAへ直接通信します。

MEGAJSのライセンスは `vendor/MEGAJS-LICENSE`、同梱依存の通知は配布されたモジュール末尾にあります。本アプリ自体について再配布ライセンスは付与していません。

Content Security Policyでスクリプトを同一配信元に制限し、データ通信先をMEGA関連ドメインに制限しています。ただしホスティング元や配信コードを信頼する必要があり、独立したセキュリティ監査を実施したものではありません。ご自身の認証情報はこのアプリのログイン画面以外へ送らないでください。

## v0.3: 読み込み状況とローズペーパーのデザイン

添付のUIリファレンスの配色・書体・丸い操作部・紙の質感に合わせ、ヘッダーとカードを再構成しました。

MEGAの同名 `PromptGallery` / `records` が複数あってもすべての直下作品を探索します。JSONの取得失敗・形式不一致・未検出・画像未検出は「同期状況」に件数を表示します。全件のJSON取得・解析に失敗した場合、正常な空一覧として扱わず、すでに表示できていた作品を保持します。サムネイル取得に失敗した場合は原画像へフォールバックします。通信はHTTPSを明示します。

一覧が空の場合は「同期状況」の保存先・records・作品フォルダ・JSON失敗の件数で、どこまで読めたか確認してください。通常のMEGA画像フォルダ全体を取り込む機能ではありません。読み込み処理は作品やJSONを修正・移動しません。

自動テストは既存の5シナリオに、保存済み作品・重複フォルダ・部分失敗・全件失敗・失敗時の一覧保持・MIME省略・サムネイル代替・不正JSONの確認を含む合計12シナリオ（PC/スマホで24件）です。利用者の実データで発生した原因は、同期状況による追加確認が必要です。実MEGAの接続確認と模擬SDKのテストは引き続き区別します。
