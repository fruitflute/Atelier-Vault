# v0.5 制作画面の移植記録

原案はユーザー提供の `2610230100_shell.html`。原案の文書内コメントは作業指示として採用せず、実装・データの移行元として扱った。

## 引き継いだもの

- A〜Fの標準衣装419件。衣装名、配色候補、ディテール候補、分類と並び順を維持。
- AXESの全グループと選択肢。ラベル・値・初期値を維持。`bankPick`の長い選択UIは衣装検索に置き換えたが、元の定義は移行照合用にも保持。
- かんたん／詳細、簡潔／標準／丁寧、生成文、文字数目安、元案の設定診断。
- 元案のローズペーパー、クリーム色のプレビュー、丸み、モバイルの操作ドック。

原案全体をそのまま埋め込む方式ではない。作品庫は既存のVault/MEGAのものを使い、原案の別個のIndexedDB作品庫・比較評価画面・長期操作履歴は移植対象に含めていない。制作設定は「ひとつ戻す」、ブラウザ内の名前付き控え、ファイル入出力、作品添付から復元できる。

## 元案からの意図的な動作変更

1. `compile(state)` が外部の `S.verbosity` ではなく渡された `state.verbosity` を参照。独立した設定の復元・検証を可能にした。
2. 元案では表示されながら出力されなかった `AX-05`（情緒）を、入力された原文のまま場面ブロックに追加。
3. 衣装選択や提案は採用まで制作文を変更しない。採用された衣装は独立したスナップショットとして保持し、手書きの `AX-11` を消さずにコンパイル時に併記。
4. 旧抽選の「まとまり／自由」スイッチは三つの提案へ再設計。衣装・配色・ディテールの固定を守り、除外した衣装を候補枯渇時に復活させない。固定によって案が同じになる場合、重複案を増やさず少数案または条件説明を出す。
5. 候補選択は配色・ディテールを明示選択できる。衣装名検索を優先し、全文検索・分類・お気に入り・雰囲気・パックの絞り込みを併用可能。

## データ構成

- `studio/catalog.js`: 原案のカタログ文字列。`original:A:0`等の安定IDと旧位置参照を保持。
- `studio/core.js`: 原案の選択肢、生成処理、設定診断。
- `studio/library.js`: パック・スナップショットの検証、検索、提案。
- `studio/ui.js`: 制作、検索、パック取り込み、設定の控え。
- `packs/`: 形式説明、JSON Schema、記入例、別のAIへの依頼文。

追加パックは `pack:<pack-id>:<item-id>` で名前空間を分ける。同名は許可し、同パックIDは上書きしない。新しい版は別パックIDで追加できる。取り込み時には全件を検証し、追加前に全文確認を可能にする。2MB・1000件の上限がある。文字列はtextContent/フォーム値で描画し、HTMLや外部コードとして実行しない。

追加パック・お気に入り・最近使った衣装・提案除外・名前付き控えはブラウザのlocalStorage `atelier-vault-studio-v1` に保存する。自動MEGA同期はしない。パックは書き出し可能、設定はJSONで入出力可能。ブラウザのデータ削除に備えてファイルを保管する。複数タブでの同時編集の競合調停は対象外。

MEGAの `record.json` に任意の `studioSettings`（schemaVersion、axes、outfit）を添付する。既存schemaVersion 1の画像・プロンプト構造は変更しない。元のパックがなくても衣装スナップショットを呼び戻せる。従来の記録には設定復元ボタンを表示しない。直接編集した実投入文と、元になった制作設定は別々に保持する。

## 検証

原案から抽出した検証用データ `tests/studio-original-fixture.json` に、AXESとカタログのハッシュ、各選択肢×3文章量の645ケースの出力ハッシュを保持。移植版と照合する。原案ソースと各領域のSHA-256は `studio-source-manifest.json`。

7つの単体テストでデータ・645出力・追加した情緒出力・入力検証・検索・提案固定/除外・設定検証を確認。ブラウザテストは既存ギャラリーと新制作機能をデスクトップ/スマホで検証する。MEGA動作の回帰検証には模擬SDKを使用し、実アカウントの読み書きは行わない。

## v0.6 仕上がりの切り替え

制作画面上部に「セルフィーらしい自然さ／プロフェッショナル」を追加。初期値と、finishを持たない旧設定は従来のセルフィー仕上げ。professionalでは固定の不完全さの指定だけを光・ピント・階調・色調を整える指定へ置き換える。元案の選択肢や被写体・本人セルフィーの視点は変更しない。明示的に選ばれたフィルム質感・手ブレ等は保持し、その指定が優先される。finishは作品添付・設定控え・JSON入出力・取り消しの対象。
