# v0.7.1 同期と操作距離の点検

## 確認できた問題と対応

- record.json の読み取りが一度失敗すると、その作品を一覧から除外していた。通信失敗だけを400ms/800ms待って2回再試行する。JSONの形式エラーは再試行しない。恒常的な失敗は件数に残す。
- 保存APIの完了と一覧の更新成功だけで保存完了を表示していた。新規作品IDが一覧に含まれるかも確認し、含まれなければ反映未確認と表示する。重複保存を促さない。
- 幅721〜1023pxは一列編集なのに固定コピー操作がなかった。この幅にも下部操作を追加。PCのプレビューではコピーを本文より上へ移動。

今回ユーザーが報告した実アカウントでの未表示原因は未確定。テストは模擬MEGAであり実アカウントの復旧確認ではない。SDKのreload(true)はキャッシュ破棄を意味しないため、その変更で修正したとは扱わない。

## デザイン評価と次の候補

ローズとクリームの配色、柔らかな角、作品を切り抜かない表示は一貫している。ただし環境によって操作への距離が変わり、制作画面は多数の設定が同じ重みで並ぶ。余白を一律に削るより、完了操作を近づける。

基本の「衣装→情緒→状況」はユーザーの衣装優先の意図に合う。さらに磨くなら、衣装の視覚的特徴（系統・素材・補足）を先、ブランド等を後へ。詳細設定の「場所・時」は「構図・撮影」より先が自然。表示方式・リセット等の管理操作は制作内容と視覚的に分ける。これらの順序変更は今回まだ適用していない。元案のラベル・選択肢・生成内容は保持している。

未表示がカード単位か画像だけか、更新で回復するか、同期状況の件数で次の診断を分ける。認証情報や画像の提供は不要。
