# v0.8.3 プロンプトの固定文を磨く

## 意図

ユーザーの選んだ表情・情緒・衣装を、固定の人物像や画質指定で弱めない。画面の項目を増やさず、人物と写真の共通説明8箇所を改訂した。

## 変更

- 人物説明の純潔・未成熟さに価値を置く固定表現を、自分の装いと写り方を選ぶ人物の説明へ。成人・18歳・日本人大学生という元の設定は維持。
- 常に照れと高揚を付ける説明を、指定された情緒・表情・目線を優先する説明へ。複雑な気分も一律の微笑みに置き換えない。
- 本人のセルフィー視点を維持し、画面外にも空間と時間が続く臨場感を説明。背景を一律に特別な時間への期待に結びつけない。
- 衣装の物理的な構造を維持しつつ、装飾密度や華やかさを選んだデザインに従わせる。
- セルフィーの手触りを残し、浅い被写界深度の無条件指定を外す。「浅い深度」を選べば従来どおり出力する。
- プロ仕上げの「落ち着いた画質」を、選んだ情緒に沿う光・色彩・コントラストへ。鮮烈な表現と繊細な表現の両方を可能にする。
- 一律の「過剰なモデル演出」回避を、指定と無関係なポーズや表情の固定の回避へ。

## 保持と適用範囲

419件の衣装、全選択肢のラベル・順序・既定値、選択肢から出力する文、手と接触の説明、保存形式、MEGA同期処理は維持。新規UIや追加操作はない。

制作画面でこれから組み立てる文章に適用する。保存済み作品のプロンプト本文は変更しない。保存した制作設定を呼び出して再生成する場合は新しい固定文を使う。

今回の対象は共通の人物説明と写真表現。画像生成は実施していないため、画像の美しさや生成モデルの追従改善を実証したものではない。

## 検証

- 元の419衣装と全コントロールのハッシュを照合。
- 元案の645ケースについて、改訂箇所と既存の手の説明を逆変換した出力が元のハッシュと一致することを検証。差分対応は `tests/prose-revision.json` に記録し、元のfixtureを上書きしない。
- 両仕上がり・全詳細度で指定された真顔・強い情緒・大きな装飾・浅い深度・逆光が残ることを検証。
- ブラウザで情緒とデザインを入力し、プロ仕上げのプレビューから作品登録欄まで同じ文章が引き継がれることを検証。
