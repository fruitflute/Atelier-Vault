# v0.9.0 鑑賞ビューア

2026-10-29。プロンプトの変更レポートを作成後に実施した、画像閲覧専用の改修。画像・メタデータ・プロンプト本文の書き換えはない。

## 画面の使い方

以前はヘッダー・フッターと内側の余白を差し引いた領域に画像を置いていた。現在は画面全体を画像領域とし、操作欄を上に重ねる。

- 全体を表示：縦横比を保ち、全体が入る最大サイズへ。小さい画像も拡大する。画像と画面の縦横比が違う場合の余白は残る。
- 画面を埋める：縦横比を保って画面全体を覆うまで拡大する。はみ出す部分は表示上切れる。ファイルを切り抜くわけではない。ドラッグで位置を動かせる。
- 実寸：画像1ピクセルをCSSの1ピクセルとして表示する。高密度ディスプレイの物理ピクセル1個とは異なる。
- ＋／−、ホイール、ピンチで拡大・縮小。拡大した画像はドラッグ。ホイール／ピンチは操作点を基準にする。拡大率の上限は800%または画面合わせ倍率の8倍の大きい方。
- 次の画像では拡大・移動をリセット。「画面を埋める」の選択のみ次の画像にも継続。新しく鑑賞を開くと全体表示から始める。
- 操作欄を隠したときも「操作を表示」ボタンを残す。画像上の中央タップやHでも戻せる。読み込み失敗時は操作欄を戻して再試行を提示する。

## 操作一覧

| 操作 | キーボード | スマホ・ポインター |
| --- | --- | --- |
| 前／次 | ←／→ | ボタン、全体表示時の左右スワイプ |
| 最初／最後 | Home／End | — |
| 拡大／縮小 | ＋／− | ボタン、ホイール、ピンチ |
| 全体表示 | \\ | 表示サイズ選択 |
| 実寸 | 0 | 表示サイズ選択 |
| 拡大画像の移動 | W A S D | ドラッグ |
| 拡大と全体の切り替え | — | ダブルクリック／ダブルタップ |
| ブラウザ全画面 | F | 右上の全画面ボタン（対応環境） |
| 操作欄の表示切り替え | H | 中央タップ、専用ボタン |
| 操作案内 | ? | ?ボタン |
| 戻る | Esc | 閉じるボタン |

Escは案内表示中なら案内を閉じ、拡大・実寸中なら全体表示へ戻し、それ以外では鑑賞を閉じる。ブラウザ全画面中のEscはブラウザ側の解除動作が先に働く場合がある。入力・選択欄やCommand/Ctrl/Optionとの組み合わせでは独自ショートカットを奪わない。

拡大中のドラッグは画像移動として扱い、画像切り替えには使わない。ピンチ後に残った指で誤って画像送りしない。画面を埋める表示で画像がはみ出している場合も、前後ボタンで切り替えられる。

## Pixeaとの対応

[Pixea公式サイトのKeyboard Shortcuts](https://www.imagetasks.com/pixea/)を2026-10-29に確認。矢印、＋／−、\\、0、WASDの割り当てを参考にした。全機能の再現ではなく、Webでの鑑賞に必要な操作を採用。ブラウザ全画面の可否はブラウザ・端末に依存する。

## 検証

PC／モバイルのChromiumで、画面寸法に対するフィット／フィル、100%表示、320～1440pxの操作欄、ショートカット、Escの段階的復帰、スワイプ、二指ピンチ、拡大時のドラッグ、設定案内、フィルタと順序、複数画像作品、フォーカス復帰、全画面要求失敗、遅れて到着する画像の破棄を検証。実機iPhone/SafariやPixeaアプリ自体の操作比較は未実施。
