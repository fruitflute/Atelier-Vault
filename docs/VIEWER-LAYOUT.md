# v0.7 鑑賞とレイアウト調整

全画面鑑賞は原画像を画面内に収める独立したdialog。閲覧中に作品データは変更しない。ギャラリーの検索・並び順に従って全画像を並べ、詳細画面から開くときは選択中の画像からその作品だけを表示する。画像ゼロ件では入口を無効化する。画像読み込みは世代番号で管理し、閉じた後や別画像へ移動した後の非同期結果は表示しない。

ブラウザのFullscreen APIは追加操作で呼び出す。非対応時は画面内の鑑賞表示を利用できる。アプリが開始した全画面は鑑賞を閉じると解除する。左右キーとボタンで移動し、閉じると元の操作位置へフォーカスを戻す。暗いプラム色の背景は鑑賞画面だけで使用する。

余白調整では、制作・登録・使い方の重複見出し、ヘッダー・フォームの間隔を整理。721px以上で選択欄を二列にし、それ未満では一列のままとした。スマホでは読み込み済み画像の高さを自然な縦横比に合わせ、65dvhを上限として全体を表示する。

## 同条件での比較測定

Chromium、viewport高さ900px。v0.6コミットe1f656eとv0.7作業版を比較。ギャラリーはデモ2作品、制作は初期状態のかんたん表示。数値はページ全体の高さで、実作品の枚数や画像の比率によって変わる。

| 幅 | 画面 | 変更前 | 変更後 | 高さの減少 |
| --- | --- | ---: | ---: | ---: |
| 390px | ギャラリー | 1883px | 1484px | 約21% |
| 390px | 制作 | 4079px | 3851px | 約6% |

390px幅で最初の画像の上端は約589pxから509pxへ移動。ボタン・文字を縮小する方法ではなく、重複と空白を主に整理した。320/390/1440pxで横方向のはみ出しと鑑賞画像の収まりを確認。実際のブラウザ全画面への切り替えと解除もローカルChromiumで確認した。
