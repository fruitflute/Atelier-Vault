# Atelier Vault 衣装パック v1

UTF-8のJSONファイルを「つくる → 衣装を選ぶ → 衣装パックを追加・管理」から読み込みます。追加前に名前・件数・同名・ID重複・全文を確認できます。同名は許可しますが、自動統合はしません。

- `schemaVersion`: 数値 `1`
- `id`: パックの固有ID。半角英小文字・数字で始まり、英小文字・数字・`.`・`_`・`-`のみ、80文字以内。同じパックIDは上書きしません。改訂版には別IDを付けてください。
- `name`: パック名、1〜100文字
- `items`: 衣装の配列。1〜1000件。ファイル全体で2MBまで。

各衣装:

- `id`: パック内で重複しないID。規則はパックIDと同じ。
- `name`: 衣装名、1〜100文字
- `category`: 原案の分類キー `A` / `B` / `C` / `D` / `E` / `F`
  - A: 日常の下着
  - B: 勝負の下着
  - C: テーマ衣装
  - D: 状態・着崩れ
  - E: 小物
  - F: 特殊
- `palettes`: 配色候補の文字列配列。1〜20個、各1〜200文字。
- `details`: ディテール候補の文字列配列。1〜20個、各1〜2000文字。
- `tags`: 任意。衣装の種類、雰囲気、色、素材など。最大20個、各1〜40文字。
- `source`: 任意。出典・作成者のメモ。1〜500文字。URLを書いてもアプリがアクセスすることはありません。

値はテキストとして扱います。HTMLや実行コードは不要です。JSONにはコメントや末尾カンマを入れないでください。`example.json` と `schema.json` を参照してください。

追加パック、お気に入り、設定の控えは現在のブラウザのlocalStorageに保存します。MEGAへは自動同期しません。ブラウザのデータ削除やプライベートブラウズでは失われる場合があるため、元のパックファイルを保管してください。取り込んだパックは管理欄から書き出せます。

保存作品には使った衣装と制作設定のスナップショットを添付します。後からパックを外しても、保存作品の設定呼び出しはできます。パックを外す操作は、MEGAの作品を削除しません。
